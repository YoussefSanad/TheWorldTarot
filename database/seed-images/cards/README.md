# Card seed pictures

Name each file `NN-slug.webp`, with two digits for the card number from 00 to 21. Only the number is matched; the slug is for humans.

Each picture must be webp, at least 640 pixels wide and 1060 pixels tall, with a width-to-height ratio within 2% of 640:1060, and under 300KB.

Cards 00 and 01 are placeholders to be replaced by files with the same names.

The card's name is printed into each picture, so it will not translate and will print twice on any screen that also lays the name in HTML.
